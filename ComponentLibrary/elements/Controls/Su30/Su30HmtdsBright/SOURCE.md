# HMTDS BRIGHT

Ручка — существующий CustomRoundSwitch из simple/Toggles/Toggle_1.
Надпись HMTDS BRIGHT и неподвижный каплевидный знак — векторное оформление.
Фрагменты изображения чертежа в компоненте не используются.
На чертеже нет числовых делений или подтверждённых фиксированных положений.
Плавное внутреннее значение 0–100%, без нанесения дополнительной шкалы.
Для ограниченного хода использован диапазон 0–300° существующего регулятора
яркости rst_nsc_bright (1CntPanel.swf; сохранённая спецификация в
_swf_component_review/ID_16_RingKnob/rst_nsc_bright/rotation.txt).
Это рабочий диапазон модели, а не подтверждение механических упоров HMTDS.
